安抚方法指南

先排查基本需求，再尝试安抚。下面是从 0 个月到 1 岁都能用的方法，按“先简单、后复杂”的顺序做。

01先排查，不要急着“翻译”哭声

  • 饿：转头找奶、吸吮手、嘴唇动；距上次喂奶久，先喂。
  • 尿布：摸一下是否湿、胀；换的时候动作慢，避免受凉。
  • 温度：摸后颈，温热不出汗即可；手脚偏凉不等于冷。
  • 拍嗝：喂后竖抱 5–10 分钟，空心掌从下往上轻拍。
  • 鼻塞 / 出牙 / 过度刺激：先离开嘈杂环境，减少灯光和逗弄。

020–3 个月：5S 安抚法

  • 包裹（Swaddle）：手臂贴身、髋部能活动；不要裹太紧。睡着后必须仰卧，不要用松毯。
  • 侧卧 / 趴卧（Side / Stomach）：只在清醒且有人看护时短时间用；绝不能趴睡。
  • 嘘声（Shush）：在耳边轻声、长音“嘘——”，音量不超过哭声；不要贴耳大声。
  • 轻摇（Swing）：托住头颈，小幅度、慢节奏；绝不能剧烈摇晃。
  • 吸吮（Suck）：喂饱后用安抚奶嘴或干净手指；不要强行塞入，注意清洁。

5S 可以组合：包裹 + 侧抱 + 嘘声 + 轻摇 + 吸吮。每做 10–20 秒停一下，观察宝宝是否开始放松。

033–6 个月：建立“吃—玩—睡”节奏

  • 清醒时间逐渐延长，看到揉眼、打哈欠、发呆就提前哄睡，别等哭到崩溃。
  • 睡前固定 3–4 步：洗澡 / 换睡袋 / 关灯 / 白噪音 / 轻拍。
  • 夜醒先等 10–20 秒，判断是饿了、尿了，还是只是翻身；不要一醒就抱起来。
  • 出牙期可以冷藏牙胶（不是冷冻），用干净手指轻压牙龈。

046 个月–1 岁：分离焦虑与边界

  • 离开前说一声、回来时打招呼；玩“躲猫猫”帮助理解“看不见≠消失”。
  • 睡前程序保持一致；可以引入小毯子/安抚巾，但睡着后拿走，避免遮挡口鼻。
  • 夜醒时先低声安抚、轻拍，尽量保持房间昏暗，不逗玩、不开大灯。
  • 白天多运动、多晒太阳；午睡不要太晚，避免过度疲劳。

05环境与声音

  • 房间 20–22°C，保持黑暗、安静；小夜灯选暖色、低亮度。
  • 白噪音放在离宝宝 2 米左右，音量约 50 分贝（比正常说话轻），不要整夜开太大。
  • 宝宝睡着后停止摇晃、降低音量；不要用热水袋、电热毯。
  • 仰睡、硬床垫、床上不放枕头、被子、毛绒玩具和防撞垫。

06可以轮流试的安抚动作

  • 飞机抱：胀气时用，喂奶后 20–30 分钟再做；头高脚低，护住下巴和脖子。
  • 竖抱拍嗝：让宝宝趴在肩上，身体前倾，空心掌从下往上；不要压肚子。
  • 推车 / 安全座椅：低速、平坦路面走一圈；不要在行驶的车里让宝宝长时间睡。
  • 皮肤接触：解开大人上衣，宝宝只穿尿布，盖薄毯，安静抱 10–15 分钟。
  • 温水澡：水温 37–38°C，5–10 分钟；发热、皮肤破损时先问医生。
  • 换人：爸爸/家人接手，换一个抱姿和房间，常常比一直换方法有效。

07哭到停不下来时，先稳住自己

  • 把宝宝放进安全的婴儿床，确认没有危险，离开 5 分钟，深呼吸、喝水、换人。
  • 回来先做“最低刺激”：关灯、少说话、包裹、侧抱、嘘声、轻拍。
  • 换环境：抱到另一个房间、推车走一圈、开抽油烟机/吹风机（保持距离）。
  • 如果怎么都不行，记录时间、持续多久、伴随症状，必要时联系医生。

绝对不要摇晃宝宝。剧烈摇晃可能造成脑损伤，甚至危及生命。

08需要就医的红旗信号

  • 3 个月以下发热 ≥38°C，或任何年龄精神差、叫不醒、反应弱。
  • 呼吸急促、费力、呻吟、嘴唇发紫、呼吸暂停。
  • 持续拒奶、尿量明显减少、哭时没有眼泪、囟门凹陷。
  • 喷射性呕吐、绿色呕吐物、血便、腹胀明显。
  • 无法安抚的持续哭闹超过 2 小时，或哭声尖直、异常。
  • 抽搐、肤色灰白、出现按压不褪色的皮疹。

以上只是常见提示，不能替代医生面诊；拿不准就打急救/儿科电话。

09不要做的事

  • 不要用力摇晃、抛接宝宝，也不要把宝宝单独留在高处。
  • 1 岁前不加盐、糖、蜂蜜；不要给整颗坚果、果冻等噎呛食物。
  • 不要趴睡、不要在床上放松软物品，不要和大人同床睡在软床垫上。
  • 不要用“让他哭到累”来训练新生儿；小月龄需要及时回应。

内容为育儿科普，不是诊断或治疗建议；早产、低体重或有基础疾病的宝宝请遵医嘱。
